# myNode Readme Doc

## Pre-Requisites

1. node
2. npm

## Installation Components

```
npm install express mysql2 redis mongodb graphql cors
npm install typescript @types/node --save-dev
npm install @types/express @types/cors --save-dev
npm install tsx --save-dev
npm approve-scripts --allow-scripts-pending
npm approve-scripts esbuild@0.28.2
```

## Commands

### 1. Generate build with code compilation

`npm run build`

### 2. Run compiled output

`npm start`

### 3. Or, execute in dev mode (required ts-node-dev (for old typescript) or tsx (for latest typescript))

`npm run dev`
